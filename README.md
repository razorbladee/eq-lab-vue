# EQ Lab

Интерактивная аудиовизуальная лаборатория на Vue 3. Приложение анализирует трек или сигнал микрофона через Web Audio API и в реальном времени рисует один из 55 Canvas-визуализаторов. Готовый кадр можно сохранить как PNG, а сессию записать в WebM.

## Что умеет проект

- 55 визуализаторов в пяти группах: волны, спектр, формы, частицы и футуристические сцены.
- Экспериментальные сцены: Phosphor Vectorscope, Cymatic Plate, Spectral Terrain, Recurrence Matrix, Magnetic Bass Field и Echo Tomography.
- Источники сигнала: локальный аудиофайл, микрофон или встроенный демо-сигнал без звука.
- 20 алгоритмов реакции на звук, включая bass punch, transient detector, compressor и cinematic swell.
- Пять частотных зон с отдельным усилением: bass, low-mid, mid, high-mid и treble.
- Жанровые настройки для EDM, ambient, rock, hip-hop, classical и речи.
- Настраиваемые цвета, фон, амплитуда, скорость, шлейф, масштаб и позиция кадра.
- Форматы 16:9, 9:16, 1:1, 4:5, 4:3, 21:9 и 2:1.
- Адаптивное качество, которое снижает сложность тяжёлых сцен при просадке FPS.
- Экспорт PNG, запись Canvas и аудио в WebM, полноэкранный режим.
- Автосохранение настроек и параметров каждого визуализатора в `localStorage`.
- Светлая и тёмная темы, адаптивные боковые панели и горячие клавиши.

## Быстрый старт

Нужен Node.js 20 или новее и npm.

```bash
npm ci
npm run dev
```

Vite выведет локальный адрес приложения. Для доступа к микрофону браузеру нужен безопасный контекст: `localhost` или HTTPS.

## Как пользоваться

1. Откройте аудиофайл, включите микрофон или оставьте демо-сигнал.
2. Выберите визуализатор слева. Поиск работает по названию и ID.
3. Настройте алгоритм реакции, жанровый пресет, частотные полосы и цвета.
4. Справа измените параметры конкретного визуализатора.
5. Сохраните кадр кнопкой `PNG` или начните запись кнопкой `WebM`.

Горячие клавиши: `Space` запускает или ставит трек на паузу, `←` и `→` переключают сцены, `R` выбирает случайную сцену, `T` меняет тему, `F` включает полный экран. Горячие клавиши не перехватываются, пока фокус находится в поле ввода.

## Архитектура

```text
src/
├── App.vue                 UI, состояние, источники, экспорт и persistence
├── main.js                 точка входа Vue и подключение дополнительных сцен
├── style.css               Tailwind и собственная дизайн-система
└── core/
    ├── audio.js            Web Audio, FFT, полосы, AGC, beat/BPM detection
    ├── engine.js           Canvas loop, resize, качество и защита рендереров
    ├── palette.js          цветовая LUT, интерполяция и glow-спрайты
    ├── visualizers.js      исходный реестр и 49 render-функций
    └── experimental-visualizers.js  6 дополнительных визуализаторов
```

`App.vue` хранит глобальные настройки в реактивном объекте и передаёт снимок состояния в `Engine`. `Audio` преобразует FFT в 160 логарифмических полос от 28 Гц до 16 кГц, применяет огибающие, эквалайзер, AGC и выбранный алгоритм реакции. `Engine` запускает общий `requestAnimationFrame`, обновляет звук и палитру, затем вызывает `draw()` активного визуализатора.

Каждый визуализатор зарегистрирован в `VIS` и содержит `id`, отображаемое имя, группу, схему параметров и функцию рисования. `VMAP` даёт быстрый доступ по ID. Состояние тяжёлых сцен хранится отдельно в `Engine.states`, поэтому массивы и offscreen-canvas не создаются каждый кадр.

## Как добавить визуализатор

Новые сцены безопаснее добавлять через `register(...)` в `src/core/experimental-visualizers.js`: исходный набор остаётся изолированным. ID должен быть уникальным, группа должна быть одной из `waves`, `spectrum`, `radial`, `particles` или `futuristic`. Параметры описываются помощниками `R` и `T`; UI инспектора построится автоматически.

Render-функция получает объект `g` с Canvas context, размерами, временем, качеством, аудиоданными, настройками, параметрами и палитрой. Используйте `g.q` для масштабирования количества частиц или сегментов, а изменяемые буферы храните в `g.st`. После additive blending или изменения alpha обязательно вызывайте `g.norm()`.

## Данные и приватность

Проект полностью клиентский. Аудиофайл не загружается на сервер: браузер читает локальный `Blob`. Микрофон используется только после явного разрешения пользователя. Настройки сохраняются локально под ключом `eqlab.v2`.

## Совместимость и ограничения

Лучше всего работают актуальные Chrome и Edge. Firefox обычно поддерживает визуализацию и PNG, но набор доступных кодеков MediaRecorder может отличаться. Safari поддерживает Web Audio и Canvas, однако WebM-запись зависит от версии браузера. Если подходящий WebM-кодек недоступен, запись может быть недоступна.

Звук нельзя запустить автоматически: браузер требует пользовательского действия перед запуском AudioContext. Микрофон не работает на обычном HTTP вне `localhost`. Экспорт WebM записывает текущий Canvas-поток с частотой 30 FPS; итоговое разрешение зависит от размера кадра и ограничения внутреннего пиксельного буфера.
