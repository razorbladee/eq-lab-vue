# EQ Lab

Интерактивная аудиовизуальная лаборатория на Vue 3. Приложение анализирует трек или сигнал микрофона через Web Audio API и в реальном времени рисует аудиореактивные Canvas-сцены.

## Что умеет проект

- Большой набор аудиореактивных визуализаторов и отдельные коллекции новых сцен.
- Источники сигнала: локальный аудиофайл, микрофон или встроенный демо-сигнал.
- 20 алгоритмов реакции на звук, пять частотных зон, жанровые пресеты, палитры и adaptive quality.
- Экспорт PNG, запись Canvas и аудио в WebM, полноэкранный режим.
- Автосохранение настроек в `localStorage`, светлая и тёмная темы, адаптивные панели и горячие клавиши.

## Эффекты

В панели **Эффекты · фоновые слои** доступны независимые слои: `Snowfall`, `Rain streaks`, `Bokeh lights`, `Fireflies`, `Floating dust` и `Aurora veil`.

Каждый эффект можно включить отдельно и настроить без изменения визуализатора:

- `Opacity`: прозрачность слоя.
- `Amount`: количество объектов.
- `Speed`: скорость движения.
- `Size`: размер частиц, капель или свечения.
- `Color`: цвет эффекта.
- `Layer`: `За EQ` рисует эффект под визуализатором, `Перед EQ` поверх него.

Эффекты подключены к общему рендер-циклу через `src/core/effects.js`. Состояния частиц переиспользуются между кадрами, количество умножается на `g.q`, а adaptive quality автоматически снижает нагрузку на слабых устройствах. При смене размера Canvas состояния эффектов сбрасываются безопасно.

## Быстрый старт

Нужен Node.js 20 или новее и npm.

```bash
npm ci
npm run dev
```

Для доступа к микрофону браузеру нужен `localhost` или HTTPS.

```bash
npm run dev          # сервер разработки

npm run preview      # просмотр production-сборки
npm run lint         # ESLint
npm run format       # исправить форматирование
npm run format:check # проверить форматирование
npm run check        # lint + format:check + build
```

## Архитектура

```text
src/
├── App.vue                 UI, состояние, источники, экспорт и persistence
├── main.js                 точка входа и подключение модулей сцен
├── effects.css             стили отдельной панели эффектов
└── core/
    ├── audio.js            Web Audio, FFT, полосы, AGC, beat/BPM detection
    ├── engine.js           Canvas loop, adaptive quality и back/front hooks
    ├── effects.js          фоновые эффекты, параметры и слой рендера
    ├── palette.js          цветовая LUT и glow-спрайты
    ├── visualizers.js      исходный реестр render-функций
    └── дополнительные модули коллекций визуализаторов
```

`Engine` очищает кадр, затем вызывает `Effects.draw(g, 'back')`, рендерит выбранный визуализатор и вызывает `Effects.draw(g, 'front')`. Поэтому эффекты не смешаны с кодом сцен и могут быть расширены отдельными функциями.

## Данные и приватность

Проект полностью клиентский. Аудиофайл не загружается на сервер, микрофон используется только после разрешения пользователя, настройки визуализаторов сохраняются локально под ключом `eqlab.v2`. Настройки фоновых эффектов живут в памяти текущей сессии, чтобы не засорять сохранённые пресеты.

## Production
