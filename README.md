# EQ Lab

Интерактивная аудиовизуальная лаборатория на Vue 3. Приложение анализирует трек или сигнал микрофона через Web Audio API и в реальном времени рисует 72 Canvas-визуализатора. Готовый кадр можно сохранить как PNG, а сессию записать в WebM.

## Что нового

Добавлена отдельная подборка **FUTURE · новое** из пяти детально проработанных сцен по мотивам новых референсов: Prism Mesh, Bass / Treble Ribbon, Pulse HUD, Spectral Core и Waveform Frame. В них есть треугольная геометрия, зеркальные отражения, слои волн, частицы, рамки, сетки, live-метрики, FFT/BPM-текст, сканирующие линии и отдельные настройки плотности.

Старые 67 сцен не переписывались. Новые сцены живут в `src/core/future-visualizers.js` и используют группу `futuristic-new`, чтобы их можно было отбирать и удалять отдельным модулем.

## Что умеет проект

- 72 визуализатора в семи логических наборах: волны, спектр, формы, частицы, футуризм, Неон и FUTURE.
- Источники сигнала: локальный аудиофайл, микрофон или встроенный демо-сигнал без звука.
- 20 алгоритмов реакции на звук, пять частотных зон, жанровые пресеты, палитры и адаптивное качество.
- Форматы 16:9, 9:16, 1:1, 4:5, 4:3, 21:9 и 2:1.
- Экспорт PNG, запись Canvas и аудио в WebM, полноэкранный режим.
- Автосохранение настроек в `localStorage`, светлая и тёмная темы, адаптивные панели и горячие клавиши.

## Быстрый старт

Нужен Node.js 20 или новее и npm.

```bash
npm ci
npm run dev
```

Для доступа к микрофону браузеру нужен `localhost` или HTTPS.

```bash

npm run format       # исправить форматирование
npm run format:check # проверить форматирование
npm run check        # lint + format:check + build
```

## Использование

Для новых сцен введите `FUTURE` или `Prism` в поиск визуализаторов. Справа настраиваются параметры выбранной сцены. `Space` запускает или ставит трек на паузу, `←` и `→` переключают сцены, `R` выбирает случайную, `T` меняет тему, `F` включает полный экран.

## Архитектура

```text
src/
├── App.vue                 UI, состояние, источники, экспорт и persistence
├── main.js                 точка входа и подключение модулей сцен
└── core/
    ├── audio.js            Web Audio, FFT, полосы, AGC, beat/BPM detection
    ├── engine.js           Canvas loop, resize, качество и защита рендереров
    ├── palette.js          цветовая LUT и glow-спрайты
    ├── visualizers.js      исходный реестр и 49 render-функций
    ├── experimental-visualizers.js 6 предыдущих дополнительных сцен
    ├── neon-visualizers.js 12 сцен из первых референсов
    └── future-visualizers.js 5 новых футуристичных сцен
```

Новые FUTURE-сцены регистрируются через `add(...)` в отдельном модуле. Они получают тот же объект `g`, используют `g.q` для adaptive quality и не создают сторонних зависимостей.

## Данные и приватность

Проект полностью клиентский. Аудиофайл не загружается на сервер, микрофон используется только после разрешения пользователя, настройки сохраняются локально под ключом `eqlab.v2`.

## Production

```bash
npm ci
npm run check
```

`dist/` является статическим сайтом и подходит для GitHub Pages, Netlify, Cloudflare Pages и обычного web-сервера.
