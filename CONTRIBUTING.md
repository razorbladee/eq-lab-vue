# Contributing

Use Node.js 20+ and start with `npm ci`. Before committing, run `npm run check`.

Use focused Conventional Commits: `fix:`, `feat:`, `refactor:`, `test:`, `docs:` or `chore:`. A visualizer must have a unique id, deterministic defaults, bounded parameters and must scale expensive work with `g.q`. Do not allocate large arrays every frame, route microphone input to speakers, or upload user media.

Bug reports need reproduction steps, browser/device details and the affected visualizer. Keep commits small enough to revert safely.
