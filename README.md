# EQ Lab

Интерактивная аудиовизуальная лаборатория на Vue 3. Приложение анализирует трек или сигнал микрофона через Web Audio API и в реальном времени рисует 67 Canvas-визуализаторов. Готовый кадр можно сохранить как PNG, а сессию записать в WebM.

## Что нового

Добавлен отдельный пакет **Neon** с 12 новыми сценами, вдохновлёнными двумя приложенными подборками: dotted curves, lollipop spectrum, spectrum ring, pulse line, mountain peaks, wave ribbon, radar sweep, track timeline, band meter, triangle peaks, frequency scale и framed spectrum. Старые 55 визуализаторов не изменялись.

Все новые сцены имеют группу `neon` и имена с префиксом `Neon`, чтобы их можно было быстро найти, сравнить и позже удалить одним модулем.

## Что умеет проект

- 67 визуализаторов в шести группах: волны, спектр, формы, частицы, футуризм и Неон.
- Источники сигнала: локальный аудиофайл, микрофон или встроенный демо-сигнал без звука.
- 20 алгоритмов реакции на звук, пять частотных зон, жанровые пресеты, палитры и адаптивное качество.
- Форматы 16:9, 9:16, 1:1, 4:5, 4:3, 21:9 и 2:1.
- Экспорт PNG, запись Canvas и аудио в WebM, полноэкранный режим.
- Автосохранение настроек в `localStorage`, светлая и тёмная темы, адаптивные панели и горячие клавиши.

## Быстрый старт

Нужен Node.js 20 или новее и npm.

```bash
npm ci
npm run dev
```

Для доступа к микрофону браузеру нужен `localhost` или HTTPS.

## Использование

Выбери источник сигнала, затем нажми группу **Неон · новое** или введи `neon` в поиск. Справа настраиваются параметры выбранной сцены. `Space` запускает или ставит трек на паузу, `←` и `→` переключают сцены, `R` выбирает случайную, `T` меняет тему, `F` включает полный экран.

## Архитектура

```text
src/
├── App.vue                 UI, состояние, источники, экспорт и persistence
├── main.js                 точка входа и подключение модулей сцен
└── core/
    ├── audio.js            Web Audio, FFT, полосы, AGC, beat/BPM detection
    ├── engine.js           Canvas loop, resize, качество и защита рендереров
    ├── palette.js          цветовая LUT и glow-спрайты
    ├── visualizers.js      исходный реестр и 49 render-функций
    ├── experimental-visualizers.js 6 предыдущих дополнительных сцен
    └── neon-visualizers.js 12 новых сцен из референсов
```

Новые сцены регистрируются через `register(...)` в отдельном `src/core/neon-visualizers.js`. Они получают тот же объект `g`, что и старые render-функции, используют `g.q` для adaptive quality и не создают сторонних зависимостей.

## Данные и приватность

Проект полностью клиентский. Аудиофайл не загружается на сервер, микрофон используется только после разрешения пользователя, настройки сохраняются локально под ключом `eqlab.v2`.

## Production

```bash

```
